# Musasizi Anthony — Personal Portfolio

Responsive portfolio website built with HTML, CSS and JavaScript.

## Preview locally
Open `index.html` in a browser. Keep the `assets` folder beside it; the photos are loaded from that folder.

## Publish with GitHub Pages
1. Create a GitHub repository (for example, `portfolio`).
2. Upload `index.html` and the entire `assets` folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. GitHub will provide your public portfolio URL.

## Contact form
The contact form opens the visitor's email application using a `mailto:` link. It does not store messages on a server.
